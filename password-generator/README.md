# Password Generator (Mini Project)

A simple, secure password generator built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — styling (dark themed card UI)
- `script.js` — password generation logic

## Features
- Adjustable password length (4–64 characters)
- Toggle uppercase, lowercase, numbers, and symbols
- Uses `crypto.getRandomValues` for cryptographically secure randomness
- One-click copy to clipboard

## How to run
Just open `index.html` in any web browser — no build tools or server required.
